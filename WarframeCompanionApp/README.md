# Warframe Companion

An iOS SwiftUI companion app for tracking Warframe Prime parts and mastery progress.

## Features

- SwiftData persistence that remains across app launches
- Live world-state data from the Warframe Status API
- Editable Helminth/subsumed Warframe overview
- Prime part inventory with quantities and ownership status
- Mastered item tracking with rank 0-30
- Search, grouping, add, delete, and progress overview
- Seed data for a useful first-run experience

## Requirements

- Xcode 15 or newer
- iOS 17 or newer

## Opening

Open `WarframeCompanion.xcodeproj` at the project root in Xcode, select an iPhone simulator, and run.
